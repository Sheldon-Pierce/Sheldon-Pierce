### About Me
I started my career studying rocks and groundwater, but somewhere between seismic surveys and sensor datasets, I found myself writing scripts to make my work easier... and never stopped. Fast-forward through a coding bootcamp, building apps for startups, and architecting large-scale systems for healthcare, government, and neurodiversity communities — and here I am: a full-time software engineer shipping microservices, APIs, and cloud infrastructure that actually make a difference.

These days you'll find me:
- Architecting healthcare microservices with .NET and Angular
- Building event-driven systems with RabbitMQ and MassTransit
- Automating cloud infrastructure with AWS, Terraform, Docker, and Kubernetes
- Coaching future developers at the UPLIFT Foundation
- Occasionally flying drones (both for fun and for science)
